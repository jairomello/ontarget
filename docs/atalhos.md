# Atalhos do ontarget

> Gerado de `apps/web/src/commands` — a mesma fonte do overlay de
> atalhos (`?`) e do dispatcher de teclas. Regenere com
> `bun run docs:shortcuts` após alterar o keymap.

## Geral

| Comando | Atalho |
| --- | --- |
| Fechar painel sobreposto | `Escape` |
| Mostrar atalhos de teclado | `?` |
| Abrir/fechar os detalhes da tarefa | `F4` |
| Desfazer | `Ctrl+Z` |
| Refazer | `Ctrl+Y`, `Ctrl+Shift+Z` |
| Alternar foco entre Task Sheet e Gantt | `F6` |

## Task Sheet

| Comando | Atalho |
| --- | --- |
| Indentar (virar subtarefa) | `Ctrl+Shift+Right` |
| Outdentar (promover um nível) | `Ctrl+Shift+Left` |
| Expandir toda a hierarquia | `Ctrl+*` |
| Recolher toda a subárvore | `Ctrl+-` |
| Expandir toda a subárvore | `Ctrl++` |
| Recolher/expandir o nó selecionado | `+`, `-` |
| Inserir tarefa | `Insert` |
| Inserir subtarefa | `Ctrl+Insert` |
| Mover para cima | `Alt+Up` |
| Mover para baixo | `Alt+Down` |

## Gantt Chart

| Comando | Atalho |
| --- | --- |
| Ampliar | `+` |
| Reduzir | `-` |
| Ajustar ao projeto | `Ctrl+0` |
| Ajustar à seleção | `Ctrl+1` |
